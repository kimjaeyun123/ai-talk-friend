Google AI Studio(aistudio.google.com)의 무료 키로 돼요. 친구 기분에 맞춰 신나게·다정하게·속상하게 말하고, 가끔 웃거나 한숨도 쉬어요. 무료 사용량을 넘으면 30분에 200원 안팎이에요.

console.cloud.google.com → "Cloud Text-to-Speech API" 사용 설정 → 사용자 인증 정보 → API 키 만들기. 키 설정의 "API 제한"에서 Text-to-Speech만 고르고, 결제 → "예산 및 알림"에서 한도 알림을 꼭 걸어 두세요. 무료 사용량을 넘을 때만 돈이 나가요.

기기에 설치된 목소리 중에서 골라요. "Google", "Natural", "Premium"이 붙은 목소리가 대체로 자연스러워요.
